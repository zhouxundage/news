01agent 的竞争点从「能调工具」转向「怎么收工」

225 个新项目里 agent 相关占 178 个（79%），但叙事已经变了。上半年比的是工具数量和协议（MCP、function calling），这个月的新项目更多在解三个问题：循环何时终止、拿不准时找谁、失败怎么重试。这是个信号——工具调用已经商品化，剩下的难点全在控制流和人在环设计上。

02skill 成了新的分发单位

这个月最值得注意的不是某个框架，而是「skill」作为打包与复用单位被大机构公开：Jane Street 放出了自家 .agents 目录，Anthropic、addyosmani 也在维护 skill 集合。本质是把「怎么用工具」的经验固化成带触发条件的文件，而不是每次重写 prompt。代价是质量参差——同一个名字下，「一句话模板」和「带边界说明与失败处理的技能包」差得很远。

03agent 走进具体设备与软件

另一条线是垂直落地：不再追求通用浏览器 agent，而是嵌进具体环境。安卓端靠无障碍服务操作 App，Blender 通过 MCP 暴露场景操作，3D 建模也在做同样的事。这类项目的价值不在模型能力，而在「把一个软件的 API 翻译成模型能可靠调用的动作」——活很枯燥，但没有替代品，而且一旦做成就是个护城河。

02替代终点正在被系统性验证

Nature Medicine 的 GFR 斜率 meta 分析（补遗）是这期最「方法学」的一条。替代终点的合法性不靠相关性，而靠「治疗对替代指标的作用能否解释对硬终点的作用」。这类 meta 分析是监管最认的论证方式，也是统计师能真正建立差异化能力的地方——比跑一个 ANCOVA 难得多，也值钱得多。

03监管批准集中在肿瘤与罕见病

近期 FDA 批准里肿瘤仍占多数（乳腺癌 ESR1 突变组合、膀胱癌围手术期），但肾病出现了「首个获批药物」这类节点。对统计师的含义：肿瘤项目的加速批准路径（ORR/DoR + 上市后确证性试验承诺）仍是主流，而罕见病与肾病更依赖单臂 + 外部对照——正好是贝叶斯借力的用武之地。

Nature Medicine 刊出一个开放式 agentic co-scientist；Expert.ai 与 Springer Nature 合作做 AI 辅助试验设计。方向很清楚：AI 在临床研究里的价值正从影像/诊断转向设计、文献、文档这些认知劳动。对做统计的人，这既是威胁也是机会——能被 agent 替代的是重复的表格生成与文献整理，不能被替代的是「这个设计能不能说服审评员」。

📌 对统计师的三条 takeaway

  1. 学 agent 的重心从「用哪个框架」转到「循环怎么终止、什么时候交给人」——新项目 79% 是 agent，但真正的难点在控制流。
  2. 替代终点与借力的方法学是这个月医药侧最值得投入的方向：GFR 斜率、Lp(a)、罕见病单臂，指向同一套论证逻辑。
  3. AI 在临床研究的落点是设计与文档，不是诊断。会写 SAP、会论证先验的人，短期内不会被替代。
